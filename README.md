# TypeScript 계산기

## 1. 계산기 소개

HTML, CSS, TypeScript를 사용하여 제작한 웹 계산기입니다.

기본적인 사칙연산(덧셈, 뺄셈, 곱셈, 나눗셈)을 수행할 수 있으며,
소수점 입력, 숫자 삭제, 부호 변경, 퍼센트 계산 등의 기능을 지원합니다.

계산 기능과 상태 관리, 화면 처리를 각각의 TypeScript 파일로 분리하여 구현하였으며,
작성한 TypeScript 코드는 JavaScript로 컴파일한 후 브라우저에서 실행됩니다.

---

## 2. 실행 방법

### 1) 필요한 패키지 설치

프로젝트 폴더의 터미널에서 다음 명령어를 실행합니다.

npm install

### 2) TypeScript 코드 빌드

다음 명령어를 실행하여 TypeScript 파일을 JavaScript 파일로 컴파일합니다.

npm run build

빌드가 완료되면 `js` 폴더에 다음 파일이 생성됩니다.

- operations.js
- calculator.js
- app.js

### 3) 계산기 실행

프로젝트 폴더의 `index.html` 파일을 브라우저에서 실행합니다.

---

## 3. 계산기 동작 확인

다음과 같은 계산 기능이 정상적으로 작동하는 것을 확인하였습니다.

| 기능 | 입력 예시 | 결과 |
|---|---|---|
| 덧셈 | 12 + 3 = | 15 |
| 뺄셈 | 12 - 3 = | 9 |
| 곱셈 | 12 × 3 = | 36 |
| 나눗셈 | 12 ÷ 3 = | 4 |
| 소수 계산 | 0.1 + 0.2 = | 0.3 |
| 숫자 삭제 | 123 → ⌫ | 12 |
| 부호 변경 | 5 → +/- | -5 |
| 퍼센트 | 50 → % | 0.5 |
| 큰 숫자 표시 | 6110000 | 6,110,000 |

또한 0으로 나누는 경우 계산을 수행하지 않고
`Error`와 `0으로 나눌 수 없습니다.`라는 오류 메시지가 표시됩니다.

오류가 발생한 후 새로운 숫자를 입력하면 오류 상태가 초기화되고
새로운 계산을 시작할 수 있습니다.

연속 연산과 계산 완료 후 새로운 숫자 입력,
AC를 이용한 전체 초기화 기능도 정상적으로 동작하는 것을 확인하였습니다.

## 4. 파일 및 함수별 역할

### operations.ts

사칙연산과 실제 계산을 담당합니다.

- `add()` : 덧셈
- `subtract()` : 뺄셈
- `multiply()` : 곱셈
- `divide()` : 나눗셈
- `calculate()` : 선택된 연산 함수를 실행

특히 `divide()`에서는 두 번째 숫자가 0인지 검사하여
0으로 나누는 경우 오류를 발생시킵니다.

### calculator.ts

계산기의 입력과 계산 상태를 관리합니다.

- `inputDigit()` : 숫자와 소수점 입력
- `selectOperator()` : 연산자 선택
- `equals()` : 계산 결과 처리
- `clear()` : 계산기 상태 초기화
- `setResult()` : 계산 결과 저장
- `handleKey()` : 입력된 버튼에 따라 적절한 기능 실행
- `pendingExpression()` : 현재 계산식을 문자열로 생성
- `formatNumber()` : 계산 결과의 숫자 형식 처리

첫 번째 숫자, 연산자, 두 번째 숫자 등의 상태를 저장하여
버튼을 여러 번 누르는 과정에서도 계산을 이어갈 수 있도록 구현하였습니다.

### app.ts

HTML 화면과 계산기의 TypeScript 로직을 연결합니다.

- `render()` : 현재 계산 상태를 화면에 표시
- `formatDisplay()` : 큰 숫자에 쉼표를 표시

각 계산기 버튼에 클릭 이벤트를 등록하고,
버튼의 `data-key` 값을 읽어 `handleKey()`에 전달합니다.

계산 상태가 변경된 후 `render()`를 호출하여
계산 결과, 계산식, 오류 메시지를 브라우저 화면에 갱신합니다.
